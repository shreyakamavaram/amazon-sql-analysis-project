# Amazon Product & Customer Review Analysis Using SQL

## Project Overview

This project analyzes Amazon product and customer review data using SQL to identify product performance, customer engagement, discount effectiveness, and category-wise business insights.

## Tools Used

* MySQL Workbench
* SQL

## Dataset Information

* Total Rows: 1465
* Total Columns: 16

## SQL Concepts Used

* Aggregate Functions
* GROUP BY
* ORDER BY
* CASE Statements
* Subqueries
* CTEs
* Window Functions

## Key Business Problems Solved

* Identified top-selling products
* Analyzed category-wise ratings
* Evaluated discount effectiveness
* Performed customer engagement analysis
* Ranked products within categories

## Sample Insights

* Electronics category had the highest customer engagement.
* Products with moderate discounts showed better ratings.
* Some highly discounted products had poor customer satisfaction.
